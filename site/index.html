Follow-me drone
Overview Replay Camera Costs Parts GitHub

Personal hobby and learning project

A drone that follows a skater, worked out one part at a time

The idea is a drone that keeps one rider in frame while they ride a pennyboard, and films them. Today it is plans, a cost model, tested Python that runs on recorded or made-up data, and models of parts to print, all developed with AI coding agents.

Nothing has flown. No hardware has been built or tested, and nothing has been ordered. The code has not been run on a drone or in a flight simulator yet. Nothing here should be used to fly anything near people.

Replay viewer

Step through a ride tick by tick: what each position source said, which ones the council trusted, and what it decided to do.

Camera

A person detector in your browser that follows only the person holding a printed marker, blurs everyone else, and shows what the follow logic would do.

Cost explorer

What the cost model says a drone costs, pass by pass, how that changes with the number of drones, and how sure the prices are.

Printable parts

Adjustable OpenSCAD models for the bench stage, shown in 3D, with STL downloads for the printers. None printed or tested yet.

The written record

The plans, decisions, corrections and history, written so that any person or AI agent can pick the project up.

Where it stands

Each stage starts only when the one before it passes. From the build plan.

  1. 1

    Software core

    Fusion of several position sources, weather and place weights, the fallback modes, companion GNSS, the follow controller and the cost model.

    ✓ Built and tested
  2. 2

    Replay

    Sensor logs run through the core. Only made-up logs so far; no real log has been recorded.

    ◐ Made-up logs only
  3. 3

    Simulator

    The follow logic against a simulated PX4 or ArduPilot drone. No real hardware.

    ○ Not started
  4. 4

    Bench

    Sensors and the rider's tag tested on a desk, motors off and props removed.

    ○ Not started
  5. 5

    Tethered or caged

    Only after the bench passes, with a human safety pilot.

    — Not planned yet
  6. 6

    Free flight

    Out of scope until stages 1 to 5 pass and the rules are checked.

    — Out of scope

How this was built

Credits

Prices come from the sellers listed in the parts catalog, each with the date it was seen. The site is plain HTML, CSS and JavaScript, built with Python's standard library and hosted on GitHub Pages. The parts page uses three.js and OpenSCAD compiled to WebAssembly, both served from this site. Full list: references.

A personal hobby and learning project. The code, tests, docs and this site were written by AI coding agents (Claude Code) at the owner's direction. No review of the code by the owner is recorded.

Nothing here claims the drone is safe, autonomous or ready to fly. This site has no analytics, cookies or tracking.
