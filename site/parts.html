Printable parts

Adjustable models for the bench stage, written in OpenSCAD, for any desktop FDM printer. Move the sliders to fit your hardware, check the result in 3D, and download the STL for the slicer.

None of these has been printed or tested. They are first designs by AI coding agents. Print the hole gauge and the test bars first, check every fit, and do each part's test before relying on it. None of them is a flight part.

Adjust

Before you print

  • Print the hole gauge first, and set the hole sizes in the other parts from it.
  • Print the test bars in each material you plan to use, and break them.
  • Weigh each print and note its print time. Those numbers replace the guesses in the parts catalog, which drive the cost model.
  • Keep anything near a spinning prop guarded, and never leave a charging battery alone.

How these are made

Each part is an OpenSCAD file in cad/ with a print card. The STL files on this page were rendered when the site was built, with OpenSCAD 2025.01.19 compiled to WebAssembly and its Manifold geometry engine. When you move a slider, that same OpenSCAD runs inside your browser, so nothing is sent anywhere.

The 3D view uses three.js (MIT licence). OpenSCAD is free software under the GPL, version 2 or later; this site serves an unmodified build of openscad-wasm with its licence, and OpenSCAD's own source is at github.com/openscad/openscad.

A personal hobby and learning project. The code, tests, docs, models and this site were written by AI coding agents (Claude Code) at the owner's direction. No review of the code by the owner is recorded.

No part here has been printed or tested. Nothing here claims the drone is safe, autonomous or ready to fly.
